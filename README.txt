PIUSBEATS WEBSITE — STARTER PROJECT

FILES
- index.html: page content and structure
- style.css: responsive layout and PiusBeats brand styling
- script.js: mobile menu, beat filters, preview placeholders and contact form
- assets/piusbeats-logo.png: supplied PiusBeats logo
- assets/audio/: put your MP3 preview files here

RUN LOCALLY
1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Install the VS Code extension named "Live Server" (by Ritwick Dey), if it is not installed.
4. Right-click index.html and choose "Open with Live Server".

AUDIO PREVIEWS
Add these files to assets/audio/ to match the sample cards:
- afro-fusion.mp3
- golden-hour.mp3
- after-dark.mp3
The preview buttons are placeholders until real audio files and a full audio player are added.

IMPORTANT BEFORE LAUNCH
- Replace hello@piusbeats.com in index.html and script.js with the official contact email.
- Replace sample beats, BPM values and artwork with real catalogue information.
- Add actual beat prices, licence types, terms and a secure payment provider before selling online.
- The contact form currently prepares an email using the visitor's email app. It does not store submissions on a server.
- This is a front-end starter. User accounts, admin tools, inventory, payments and secure downloads require a backend and payment integration.
